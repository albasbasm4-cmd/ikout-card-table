# iKout Card Table

قم ببناء وتشغيل لعبة كوت التفاعلية iKout Card Game استناداً إلى أحدث نسخة من مستودع GitHub (albasbasm4-cmd/ikout-card-game) بجميع شاشاتها وتحديثاتها الأخيرة:
1. شاشة البداية والملف الشخصي (اختيار الاسم والشخصية من الـ 32 شخصية وأيقونة اللاعب).
2. شاشة التدريب والإعداد وشاشة الغرفة (الغرفة، المقاعد، البوتات، مشاركة الرابط/QR).
3. طاولة اللعب الأصلية بطابع الخشب (wood background)، مروحة الأوراق المقوسة لليد، شبكة كروت الطاولة الثابتة، وأزرار الاختصارات والدردشة الصوتية المربوطة بالشخصيات.
4. منطق اللعبة الكامل وقواعد الكوت (الحكم، المزايدة، الذكاء الاصطناعي للبوتات مع تأخير التفكير، والسكور).
تأكد من أن التصميم متجاوب ومثالي للهواتف والوضع الأفقي.
